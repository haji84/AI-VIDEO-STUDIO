# BGM・SE 素材利用・配布ライセンス記録

更新日：2026-10-21。正式な商用配布前に必ず再点検する。

| 種類/出典 | アプリへの同梱 | 完成動画に利用 | 必要な扱い |
|---|---|---|---|
| 自作のSE/BGM | 原則可能 | 原則可能 | 他人の曲を模倣/流用していないこと、元音源を保存 |
| Creative Commons CC0 | 利用許諾上は比較的自由 | 同左 | 権利元とCC0指定の真正性を記録。商標・人格権等は別 |
| CC BY 4.0 | 条件付き | 条件付き | 原作者、ライセンス、変更有無などの表示が必要 |
| CC BY-NC 4.0 | 商用サービスには採用しない方針 | 非商用条件次第 | 将来の課金/収益化と衝突するため候補から除外 |
| Freesound | **各ファイルのライセンスで判断** | 同左 | CC0/CC BY/CC BY-NCが混在。サイト名だけで許諾を決めない |
| Pixabay | **音源単体再配布には制限。原則同梱しない** | 作品の一部としての利用は許諾条件次第 | 作品への使用と、素材パックとしての配布は別 |
| CapCut内蔵素材 | 許諾確認まで禁止 | 出力先/利用条件を個別確認 | CapCutにあるから独自アプリへ持ち込めるわけではない |
| 利用者が読み込んだ音源 | 再配布しない | 利用者に権利確認UI | ライセンス元・必要な表記・公開条件を保存 |
