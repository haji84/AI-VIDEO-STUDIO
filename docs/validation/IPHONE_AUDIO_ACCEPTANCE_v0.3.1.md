# iPhone実機：SE/BGM受入試験手順（未実施）

**実機PASSの条件：iPhone上で生成したログと完成動画を回収し、内容を確認すること。** PC/Chromiumの結果は代用にならない。

## フェーズA：ブラウザ試作（費用・クラウド不要）

1. `audio_prototype/AUDIO_PREVIEW.html`をiPhone Safariで実行できる形で開く。ファイルアプリ内のテキスト表示ではJSが動かない場合がある。必要なら許可された静的HTTPSの非公開ホストにHTMLだけ置く（動画や音声はアップロードしない）。
2. 「テストSEを鳴らす」を押して音が聞こえるか。iPhoneのサイレント設定・ブラウザの音声許可も記録。
3. 自分で権利を持つ短いBGM、SE、10秒程度の自分の動画を選択。
4. BGMを-19 dB/ -30 dBで切り替えて聴感と音量差を確認。SE開始時刻を1.5s、3.0sと変え、指定位置で音が鳴るか比較。
5. 「会話中BGMを下げる」をON/OFFし、手動入力の区間で音量変化するか確認。これは自動VADではない。
6. 設定JSONを書き出し、File名・開始時刻・音量値が保存されていることを確認。素材ファイル自体が外部へ送信されていないことを確認する。

**注記**：このフェーズの音声時刻・減衰は試作。WebAudio上の端末プレビューで、完成MP4の品質/タイミング一致は検証できない。

## フェーズB：iOSネイティブ試作（開発後）

1. AVAudioEngineで元音声+BGM+SE+ナレーションの少なくとも4バスをミックス。
2. 動画再生の一時停止・シーク・ループ・SE複数配置で音が二重に鳴らない。
3. AVFoundationで編集後MP4を書き出し、指定したSE開始時刻とBGMダッキング量を測定。
4. プレビューと完成物の音の開始時刻・音量・フェードを比較。イヤホン/スピーカー両方で確認。
5. 端末ロック/アプリ中断/電池残量低下で保存・再開が機能することを検証。
6. 単に短いテストがPASSでも4K・約11GBの素材で動くと宣言しない。

## フェーズC：初心者テスト

- 利用者が「BGM試聴→追加→音量調整」「SE試聴→配置」「会話中だけBGM小さく」「戻す」「完成」を説明書なしで行う。
- ボタンの文字/プレビュー/タッチ範囲/誤操作からの回復を観察し、操作できなかったところを修正。

## 記録するデータ

端末型番、iOS版、ブラウザ/アプリ版、素材形式、素材時間、音量設定、経過時間、CPU/電池/発熱、失敗・原因、元データHash、完成動画Hash、独立した聴感確認、結果PASS/FAIL/INCONCLUSIVE。
