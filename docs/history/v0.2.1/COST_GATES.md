# コスト上限制御（実装・運用ポリシー）

- Ownerの月額支出目標：500〜1,000円。**目標でありクラウド請求の絶対上限ではない**。
- 承認なしの新規有料契約、Cloud Run Jobs起動、GPU推論、Stripe販売は無効化。
- Workers APIのコードには実行ゲート2種類（PROCESSOR_ENABLED / CLOUD_PROCESSING_APPROVED）があり、片方だけでは実行できない。
- R2の保存には費用が発生し得るため、1ファイル8GiB・プロジェクト24GiBの試験制限。これだけで総請求を保証できない。
- 保存バイト、動画分数、クラウドCPU/GPU利用時間、総エンコード時間、オブジェクト操作数をジョブ別に計測予定。
- 保存期間の自動削除は独立承認・元データ保護・ダウンロード確認が必要。勝手に原本は削除しない。
- 失敗ジョブの無制限再試行は行わない。実クラウド版は作業回数上限・並列度・最大実行時間・プロジェクト当たり総容量上限を導入する。
- 決済・サブスクは後日。usage_ledgerは利用量の内部集計であり請求書ではない。

## v0.2.1の追加安全設定

標準試験容量は全プロジェクト合計32MiB。大容量実素材は `LARGE_UPLOAD_APPROVED=1` と `STORAGE_COST_APPROVED=1` の両方、および明示的な `MAX_PREVIEW_STORAGE_BYTES` を要する。アプリ側上限はCloudflareの実際の請求上限とは異なるため、請求設定と監視の実確認なしに利用者の11GB動画を投入しない。Cloudflare R2は未有効化、請求状態は権限不足で未確認。
