# AI VIDEO STUDIO v0.3 再設計・端末能力調査パッケージ

更新：2026-10-21

**これは設計・技術調査・実機事前確認ツールです。完成動画編集アプリではありません。**

## ファイル

- `SPEC_v0.3.md`：新たなローカル優先仕様、初心者向け編集、複数カメラ、音声、エフェクト、QA、保存設計、段階的完成条件。
- `FEASIBILITY.md`：公開APIの技術成立性と、iPhone/Android/PCの未検証項目を明確化。
- `DEVICE_CHECK.html`：ブラウザ機能検査＋短尺動画の明暗・フレーム変化検査＋テロップ効果サンプル＋TTS声の検出。
- `DEVICE_CHECK_PREVIEW.png`：事前確認画面のスクリーンショット（Chromiumで作成）。
- `VOICE_LICENSE_MATRIX.md`：CapCutの声を直接コピーするのではなく、合法的に使える候補を比較する台帳。
- `CODEX_HANDOFF.md`：今後の実装タスクの引継ぎ書。
- `TEST_RESULTS.md`：今回実施した限定的な実行テストと未実証の境界。

## DEVICE_CHECK.htmlの使い方

- iPhoneのSafariやAndroidのブラウザでHTMLページを開ける環境が必要。アプリ内プレビューやファイルアプリでJavaScriptが動かない場合は、開発用の安全なHTTPS静的ホストに**ページだけ**置く（動画は送らない）。このパッケージは未公開・未配置で、静的ホストを勝手に作成していない。
- 「ブラウザ機能を検査」を押し、その後必要なら自分の短いテストMP4を選ぶ。
- 「3場面の明暗・変化を測定」で端末内ブラウザの動画フレームをサンプリングする。大容量の素材で試す必要はない。
- テロップエフェクトは見た目のデモであり、書き出し機能ではない。
- 「日本語を読み上げる」は、音声候補と再生の簡易試験。音声がオフラインで生成される証拠ではない。
- 結果JSONを保存して後で比較する。入力した動画はサーバーへ送信しない（アプリ内に外部通信処理はない）。

## 過去v0.2.1との関係

v0.2.1はクラウド中心の実験版として保持する。v0.3はその置き換えに向けた新仕様草案。コード改修やネイティブアプリの実機導入は次の開発工程であり、旧版の既存機能を完成と偽らない。
