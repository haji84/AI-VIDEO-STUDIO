# Codex開発引継ぎ（実行未開始）

AI VIDEO STUDIOはGORIQと別製品。`SPEC_v0.3.md` を新仕様草案、`FEASIBILITY.md` を技術成立性調査、`VOICE_LICENSE_MATRIX.md` をライセンス棚卸しの基準とする。

1. 既存v0.2.1 ZIPを読み、既存コードの変更箇所を現物確認する。cloud中心設計を捨てるのではなく、local-firstを新しい既定モードにする。既存API/FFmpeg/タイムラインの再利用範囲を明確化する。
2. iOS, Android, PCを分けて技術スパイク。初期はiOSでAVFoundation/Apple Vision/端末Speech/TTS/エフェクト出力の実機を優先し、Android Media3と共通スキーマへ展開する。PCを起動していないと使えない設計は禁止。
3. AI音声はまずOS標準TTSで日本語の実ファイルを作り、後からKokoro等のローカルモデルを拡張する。CapCut固有の音声資産や映像エフェクトを無断コピーしない。
4. 「効果プリセットをタップ→プレビュー→強さ調整→書き出し」の少ない操作数を最優先。テロップと映像エフェクトの共通定義と、プレビュー対完成の一致試験を作る。
5. 合成動画単体テスト・ローカルPC試験・iPhone実機試験・Android実機試験・実11GB試験の結果を分ける。機械にアクセスできない工程は未実施とする。
6. 自動編集で訓練の意味・安全手順を推測で断定しない。同期不良・誤字幕・不確定な意味解析は修正候補または要確認とする。
7. 追加課金、クラウド送信、アカウント作成、権限変更、公開は禁止。本人の承認が必要な場合は、具体的な対象と費用・影響を示す。
8. ローカルAIの消費電力/メモリ/処理時間を保存し、対応能力の低い端末では低解像度プロキシ・順次処理・機能縮退を実装。
9. 開発成果の判定はコード量ではなく、実機で操作して再現できる完了要件と保存された証拠に基づく。

この引継ぎ文書は開発開始・実機試験成功の証拠ではない。
