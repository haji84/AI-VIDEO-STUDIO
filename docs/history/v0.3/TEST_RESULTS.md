# AI VIDEO STUDIO v0.3 技術調査・試験結果

実施日：2026-10-21

## ソース調査

Apple Vision / AVSpeechSynthesizer、Google Media3 / MediaPipe、whisper.cpp、CapCut公式のAI音声仕様、Kokoro-82M、VOICEVOX/VOICEVOX Nemoの使用条件を一次資料に基づいて確認。公開API／公開実装の存在と、個々の端末で実用速度・精度が出ることは区別している。

## 今回実行した試験

1. v0.2.1のREADME/STATUS/アーキテクチャから、既存クラウド型アプリの設計範囲と未完了部分を整理（読み取りのみ）。
2. `DEVICE_CHECK.html` のJavaScriptをNode.jsで構文解析 → PASS。
3. Chromiumのheadless環境（390px画面）でHTML表示・基本API検出・エフェクト切替→PASS。ページ内JavaScript例外なし。**Chromium上の結果でありiPhoneの結果ではない**。
4. FFmpeg 7.1.5で生成した3秒／320×180／3色切替のH.264 MP4を、Chromiumブラウザ内の動画ファイル入力から実際に読み込んだ。
5. Canvasで3フレームを抽出し、明るさおよび各フレームとの差を計算 → PASS。

抽出値（人工MP4）：

| 時点 | 輝度平均 | 前の標本とのピクセル差平均 |
|---|---:|---:|
| 0.3秒 | 54 | なし |
| 1.5秒 | 92 | 38 |
| 2.6秒 | 18 | 74 |

これで、ブラウザ内での小さなMP4を使った**簡易映像解析処理**は動いた。代表フレームに対する数値計算だけの実証であり、AIによる意味理解ではない。

## 検証ができなかったもの

- この環境のブラウザからローカルファイルURL／localhostへのページ遷移は許可されず、ページコンテンツ直接設定で試験した。iPhoneのSafariへの配置や読み込みは実証していない。
- iPhone/AndroidのネイティブAPI実行、Core ML/MediaPipe/Whisper推論、Webからの音声保存とオフライン検証、長尺・大容量の動画出力は実施できない。
- 元の11GBの素材を取得していないため、同期精度や360度映像を評価できない。
- CapCutの特定の声の利用権限や同一音色の再現可否は不明であり、無断使用を設計に含めていない。

## 解釈

「端末内でできる技術的な仕組みがある」「一部の簡易解析がブラウザで実動作した」は裏付けられた。
「iPhoneでAI自動編集が実用速度で完成する」「訓練の技術動作を正しく理解する」は未実証。実機ベンチが必要。
