# AI VIDEO STUDIO v0.3.1 | BGM・SE 音声編集の正式仕様草案

更新日：2026-10-21
状態：仕様追加 + **FFmpegの合成音声による局所的試作成功** / iPhone・Android実機未検証

## 1. 基本方針

- AI VIDEO STUDIOは端末内保存・端末内編集が既定。クラウド音源検索、BGM合成API、音声処理APIへ自動送信しない。
- 動画本数は1〜N本。同期しているカメラのうち、視聴者に聞かせる元音声トラックをユーザー/AIが選べる。**全カメラの音声を無条件に加算しない**（二重音声、ハウリング、位相干渉回避）。
- 元動画の音声、AIナレーション、BGM、SEを互いに独立した非破壊トラックで保存する。端末からの素材移動・権限失効は再リンク画面で回復。
- 音声が聞き取りやすいことを映像演出より優先できる「教材/説明重視」モードを用意する。

## 2. 初心者向けUI（最低操作）

1. 編集画面下部に「🎵 BGM」「✨ SE」「🎙️ 音声」「音量」タブ。音声一覧には分類、短いプレビュー、権利バッジ。
2. 音源タップ → 再生/試聴 → 「この場面へ追加」。初期位置は再生ヘッド位置。
3. 追加後は波形付きクリップを指で左右に移動して開始時刻を変える。長さは両端をドラッグ。
4. BGM「全編に合わせる」「ここだけ使う」「繰り返す」「フェード」「音声中は小さく」を1タップで操作。SEは「強さ」「長さ」「遅延」を調整。
5. AI音声の台本変更時に関連するナレーションの音声を再生成し、同じ領域だけBGMを自動調整。
6. 一操作戻す・やり直す、音源置換、ソロ試聴、ミュート、自動保存、書き出し前の全音声試聴を必須。

## 3. BGM仕様

- カテゴリ候補：ドキュメンタリー、落ち着き、明るい、緊張感、壮大、技術解説、ショート向け。
- 「動画の雰囲気から提案」は編集目的、音の強弱、カット密度などの説明可能な特徴に基づく。専門的な技術場面で緊張演出を勝手に加えない。
- 対応：曲の部分使用、複数BGM、交差フェード、冒頭/終端フェード、ループのつなぎ目処理、映像尺に合わせた調整、拍検出・ビートガイド。
- 映像カット位置をビートに寄せるのは任意。教材モードでは時系列・技術動作の確認を優先し、拍に合わせるために重要な場面を捨てない。
- デフォルトは音声/ナレーションが明瞭な控えめレベル。開始例：元音声0 dB、BGM -19 dB。**実素材でラウドネスを測り最終値を決める。**

## 4. SE仕様

- ワンタップカテゴリ：ポップ、ピン、ページ切替、スウッシュ、クリック、ズーム、完了、注意、カウント、字幕出現。
- 重要な台詞や指示に被るSEは自動で小さくする/短い代替音を提示。警報や実際の周囲音を消すような自動処理をしない。
- テロップ/トランジションの `effectId` にSEを任意リンク。元の動画にあるSEではなくアプリで追加したものは独立トラックへ。音源がない場合は無音効果として安全に表示。
- 複数のSE配置、ドラッグ移動、長さ、パン、音量、ミュート、同時発音数制限、ワンタップ試聴、差し替えを実装する。

## 5. 音量・ダッキング（優先度高）

- 音量操作はdB表示、内部はサンプルゲイン。過大ピーク/クリッピングを回避するリミッターを最終段に置く。
- 元音声/指示/AI音声がある時だけBGMを小さくする**自動ダッキング**。音声区間はVAD/ASRからの推定と手動指定の両方を持つ。VAD誤判定の場合はワンタップ修正。
- 初期案：会話開始前から緩やかに下げ、終了後ゆっくり戻す。試験用の固定値として `duckGain=0.22` を用意するが、最終初期値は聴感試験で調整。
- 原本音声への処理は非破壊。オリジナルの明瞭さを保つ専用レベル設定を別プロジェクトに保存。
- 音源のミックスプレビューと完成ファイルの時刻/ゲイン/ループの一致を機械テスト + 実機聴感で検証する。

## 6. 同時編集・音声の時間モデル

- すべての音声は共通タイムライン秒数 `startSec` に置く。元動画独自の秒数は各カメラの同期オフセットで換算する。
- 1つの素材音声を採用する場合と、必要箇所だけ別カメラ音声へ切り替える場合をサポート。重なりの継ぎ目には短い音声クロスフェード。
- 自動配置候補は `source time`, `target time`, `confidence`, `reason` を記録し、AI推定位置が低確度なら仮置き・要確認とする。
- プロジェクト JSON の例：

```json
{
  "audioVersion": "0.3.1",
  "audioBuses": ["source", "narration", "bgm", "sfx"],
  "audioAssets": [
    {
      "assetId": "asset-bgm-1",
      "mediaKind": "bgm",
      "localRef": "user-selected-file",
      "licensing": {"kind": "owned", "sourceUrl": null, "author": null, "requiresAttribution": false}
    }
  ],
  "audioClips": [
    {"id": "music1", "assetId": "asset-bgm-1", "bus": "bgm", "startSec": 0, "endSec": 20,
     "trimInSec": 0, "loop": true, "gainDb": -19, "fadeInSec": 0.5, "fadeOutSec": 1,
     "ducking": {"enabled": true, "voiceIntervals": [[3, 6]], "gainFactor": 0.22}},
    {"id": "fx1", "assetId": "asset-se-1", "bus": "sfx", "startSec": 1.5,
     "endSec": 1.75, "gainDb": -9}
  ],
  "master": {"truePeakLimitDbTP": -1.0, "loudnessTargetLUFS": null},
  "revision": 1
}
```

`truePeakLimitDbTP` は将来の音量処理設計値。**現行の試作実装にLUFS/true peak保証はない**。

## 7. ライブラリと利用権

- **CapCutアプリ内のBGM/SEを無断コピーしてAI VIDEO STUDIOへ収録しない**。利用許諾は素材ごとに別。
- 最初の「内蔵無料」ライブラリは、自作の音源か、アプリへの再配布も許可されていることを確認した音源に限定。外部サイトからユーザーが自分で取得した音源を読み込むこととは区別する。
- 各音源に `author`, `sourceUrl`, `licenseId`, `requiresAttribution`, `restrictions`, `reviewedAt` を保存。出力物へ必要なクレジット一覧を生成。
- 不明な権利の音源は試聴/編集に使えても、一般公開前に「配信・商用使用の権利を確認してください」と警告する。ライセンス不明を勝手に無料商用可と扱わない。
- Pixabayは完成作品への利用と、音源単体の再配布に異なる条件がある。無審査で楽曲をアプリ同梱しない。Freesoundは CC0/CC BY/CC BY-NC などファイルごとに異なる。
- 将来SaaSの音源ライブラリ公開は、音源を配布する行為そのものに対するライセンス確認と原価・著作権監査を別工程にする。

## 8. エンジン・検証

- iPhone: AVAudioEngine/AVAudioMixerNode、AVFoundationベースの音声・映像合成、生成AIナレーション音声のタイムライン配置。
- Android: Media3 Transformer Composition、音声処理グラフ。Windows/Mac: 既存FFmpeg編集エンジンの音声トラックを拡張。
- ブラウザ試作: Web Audio API (`GainNode`) によりユーザーが選択したBGM/SEと元動画を端末上で試聴。iOS SafariはHTMLMediaElement.volumeが期待通り機能しないことがあるため、WebAudioノードを使用する。
- 初期実装の試験: 人工動画＋自作合成音声でBGM/SE/ナレーションを混合し、指定時刻にSEとナレーションが現れ、ナレーション中のBGMが減衰することを周波数成分で確認。MP4の全編デコード PASS。
- ただし合成音源に対するテストは、声の自然さ、専門的音声の聞き取りやすさ、BGMの音楽的つなぎ目、iPhone実機のエクスポート性能を証明しない。

## 9. 完成条件

1. BGM/SEを端末から読み込み、プレビュー、タイムライン配置、保存・再開・やり直しができる。
2. 元音声・BGM・SE・AIナレーションを別々に音量調整できる。楽曲の繰り返し・フェード・ダッキングが確認できる。
3. iPhone実機でのプレビューと完成MP4の音量変化・開始時刻差を測定。音のズレを見逃さない。
4. 初心者が説明書なしで「BGM追加」「SE追加」「ナレーションが聞こえる音量にする」「出力」を完了できる。
5. オフライン設定でBGM/SEが利用でき、外部送信していないことを検証。
6. 内蔵素材、外部取込素材の利用許諾と必要な表示を確認。商用化判断は別工程。
7. AIにBGM/SEを提案させた場合も編集理由・候補・適用位置が修正可能である。

## 補足

現在の`audio_prototype/mix_audio.py`はローカルFFmpeg用の実行可能な**限定試作**。動画カット、複数カメラ再同期、AI音源選定、スマホネイティブ動画レンダラーには未接続。`audio_prototype/AUDIO_PREVIEW.html`はブラウザの局所的音声プレビューで、完成MP4出力ではない。
