# AI VIDEO STUDIO v0.1（独立プロジェクト）

**ZBook上で複数カメラの素材をローカル編集できる、初期試作版です。** GORIQのリポジトリや稼働サービスは使用・変更しません。編集用動画をクラウドにアップロードしません。無料のPythonとFFmpegを利用します。

> 開発状況：人工的なテスト動画を使用した10件のテストがPASS。ZBook実機の約11GBの元動画を使った検証、高度な映像意味理解、AIによる教材品質判定は未完了です。「完全なAI自動編集アプリ」とはまだ呼びません。

## 初回だけ準備すること（Windows 11）

1. ZIPを展開し、フォルダを `C:\VideoEdit\AI_VIDEO_STUDIO` などに置く。元動画は移動しなくて構いません。
2. `setup_windows.bat` をダブルクリックしてPython 3とFFmpegの有無を確認する。Pythonがない場合は公式サイトを開きます。FFmpegがない場合は、確認後にWindows標準の `winget` で無料版の導入を選べます。勝手にインストールはしません。
3. `start_windows.bat` をダブルクリックする。ブラウザでローカル編集画面が自動で開きます。接続は `127.0.0.1` のみです。

PowerShell、Codex、GORIQの起動は必要ありません。**アプリは起動中の黒いウィンドウを閉じないでください。** ZBookをスリープさせると処理は続きません。

### 初回に使用する素材

- `C:\Users\<USER>\Desktop\sample_camera_a.mp4`（事前確認：4.42GB）
- `C:\Users\<USER>\Desktop\sample_camera_b.mp4`（事前確認：6.59GB）

「＋ 動画を選ぶ」から2本を選んでください。後日、3本以上の素材にも対応します。OneDriveのオンライン専用ファイルは、あらかじめ「このデバイス上に常に保持する」にするなど、**完全にローカルで読み出せる状態**が必要です。

## 操作の流れ

1. **動画追加**：複数ファイルをまとめて選択する。PCの元動画は参照のみで変更・削除しません。
2. **音声同期**：2台以上の撮影開始時刻の差を推定する。異なるマイクの音では誤差が出ます。自信がない場合は「未確認」と表示し、手動調整できます。
3. **自動配置**：時系列でカメラを切り替える編集の下書きを作る。重要場面を意味で選ぶAIは、まだ未実装です。
4. **かんたん編集**：区間を選び、カメラ変更・2画面・テロップ・スロー・区間長変更・並べ替え・分割・削除。操作は自動保存。元に戻す・やり直し可能。
5. **Ollama編集相談（任意）**：ローカルOllama（既定モデル `qwen2.5-coder:3b`）が編集案を提示。自動適用はしません。モデルがない場合は省略可。
6. **MP4書き出し**：フルHD/720p/540pを選び、GPUが使えれば優先。失敗時は全区間をCPUで再実行。書き出したMP4は全フレームのデコードをチェックします。

出力先：`workspace/projects/<プロジェクトID>/exports/`。プロジェクト情報は同フォルダの `project.json`、履歴は `history/` に保存されます。

## 注意

- 画質を落として元動画を上書きすることはありません。圧縮は書き出し時にのみ行います。
- 360度素材については、**等距円筒（equirectangular）のMP4だけ**固定視点の変換に対応します。元INSVを直接読むことはできません。X3のINSVはInsta360 Studio等で360度MP4に変換してください。視点の自動追尾は未実装です。
- 2台以上の音声の相関で合わせるため、離れた隊員が別々の音を収録している場合は同期に失敗する可能性があります。「同期候補」は正式な確認ではありません。
- 自動編集の下書きは意味を理解して重要場面を選んでいるわけではありません。無理な短縮による場面欠落を避けるため、基本編集では時系列を残しています。
- 同時に使える台数はPC性能・空きディスク・素材長で制約されます。大容量の場合、書き出しに時間がかかることがあります。
- 今後の高度な映像理解AI、テレビ番組レベルの演出、全編の意味的な検査と自動修正には追加開発が必要です。
- 不明な訓練技術の解説を自動で捏造しない設計です。技術的正確性の最終確認は人が行ってください。
- このアプリはローカルで動き、GH Actions、既存のGORIQプロセス、接続済み外部サービスにはアクセスしません。

## 開発・テスト

Python標準ライブラリのみでアプリとブラウザ画面を実装。FFmpeg/FFprobeを動画処理に使用します。

```bash
python -m unittest discover -s tests -v
```

上のテストでは合成MP4を作成するため、FFmpegが必要です。`studio/core.py`に編集・音声同期・書き出し、`studio/server.py`にローカルUI・永続化・ジョブが含まれます。

詳細は `STATUS.md` と `ARCHITECTURE.md` を参照してください。
